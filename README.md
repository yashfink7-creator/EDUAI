# EDUAI — AI Teaching Co-Pilot

AI-Powered Teacher Assistance & Lesson Planning Platform

## Problem

Teachers spend significant time preparing lesson plans,
classroom activities, assessments and learning materials.

## Solution

EDUAI is an AI-powered teaching assistant designed to help
teachers plan, create, adapt and assess lessons efficiently.

## Features

- AI Lesson Planner
- AI Teaching Assistant
- AI Quiz Generator
- Adaptive Lesson Planning
- Lesson Library
- Teacher Dashboard

## Tech Stack

- React
- Node.js
- Express
- MongoDB
- AI API
